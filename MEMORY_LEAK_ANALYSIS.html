2. Circular References in UI Hierarchy

Risk Level: MEDIUM

Parent-child relationships in UI (add_child/remove_child) can cause circular references if not properly managed.

✓ Good Pattern in Your Code:

ScoringView.vala lines 158, 172:

if (scoring_view != null)
    remove_child(scoring_view);
scoring_view = null;

Properly removes child views before replacing them.

⚠️ Watch For:

Views that keep references to their children AND children keep references back to parent without using weak or unowned.

Use Weak References When Appropriate:

// Use weak reference for parent-child cycles
public class ChildView : View2D
{
    private weak ParentView parent;  // Won't prevent garbage collection

    public ChildView(ParentView parent)
    {
        this.parent = parent;
    }
}

General Recommendations

1. Add Cleanup Methods to Key Classes

Every class that connects signals should have a cleanup method:

public class MyClass
{
    public void init()
    {
        object.signal.connect(handler);
    }

    public void cleanup()
    {
        if (object != null)
            object.signal.disconnect(handler);
    }

    ~MyClass()
    {
        cleanup();
    }
}

2. Use Weak References Appropriately

// Prevent circular references
weak ParentObject parent;
unowned ChildObject child;  // When you don't own the object

3. Profile Memory Usage Periodically

Use Valgrind to detect memory leaks during development:

valgrind --leak-check=full --show-leak-kinds=all ./bin/Northeast-Mahjong

# Or use Massif for heap profiling
valgrind --tool=massif ./bin/Northeast-Mahjong
ms_print massif.out.<pid>

4. Clear Collections Explicitly

// When transitioning between game states
public void reset_round()
{
    tiles.clear();
    players.clear();
    call_history.clear();
    animations.clear();
}

5. Test for Leaks During Long Sessions

  • Play multiple rounds and check memory usage
  • Monitor with top or Activity Monitor
  • Look for steadily increasing memory usage
  • Test reconnection scenarios (disconnect/reconnect multiple times)
